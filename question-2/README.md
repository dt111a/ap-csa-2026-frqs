# Question 2: Classes

Question 2 of the APCSA 2026 FRQ involves creating a Bottle class that udpates the amount of water within a water bottle when a user changes it. 

## My Approach
I walked through the problem by first creating the outline of the entire code block by outline the necessary instance variables, constructors, and helper methods. Then, I read each of the instances that the Bottle would change, such as an update of the bottle amount of water by the method call, and this helped me create the class. 

## Course Connections 
This is similar to the New Year ball Drop Confetti project because both code blocks involved using classes for each type of object (in this case bottle vs each particle within the confetti code) 

## What Gave Me Trouble 
I think that the problem was fairly straight forward, but I think one thing I struggled with was determining the amount of instance variables necessary for the code to run. After I got past that, the rest of the code was fairly easy. 

## What I would do differently 
If I were to approach this problem again, I would probably read the problem entirely through before coding in order to save on time and more. Additionally, I might simplify code as well, as I think I had a lot of unnecessary declarations and initializations of variables.
